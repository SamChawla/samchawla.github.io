# samchawla.github.io

Personal profile site for **Sumit S Chawla** — Technical Lead. An interactive
**Ubuntu-desktop portfolio** (GNOME/Yaru style) with a boot screen, dock,
draggable windows, and a working terminal. Built with
[Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages.

**Live:** https://samchawla.github.io

The home page (`index.html` → `_layouts/desktop.html`) renders the desktop; each
"app" window is an include in `_includes/windows/`, and the window manager +
interactive terminal live in `assets/js/main.js`. The `/blog/` section uses the
simpler `default` layout. All windows are populated from the `_data` files below.

## Editing content (no HTML required)

All content lives in `_data/*.yml`. Edit those and the site updates:

| File | What it controls |
| --- | --- |
| `_data/profile.yml` | Name, role, headline, summary, hero CTAs, stats, résumé link |
| `_data/projects.yml` | **Featured projects** — name, blurb, metric, stack, links |
| `_data/experience.yml` | Work history timeline |
| `_data/skills.yml` | Skill groups and chips |
| `_data/education.yml` | Education entries |
| `_data/social.yml` | Footer/contact links |

> The most important field is `metric` in `projects.yml` — a measurable outcome
> (e.g. "Cut p95 latency 800ms → 120ms"). Replace the placeholder projects with
> your real ones.

### Writing / blog

Add a Markdown file to `_posts/` named `YYYY-MM-DD-title.md` with front matter
(`layout: post`, `title`, `date`, `tags`, `excerpt`). It appears automatically on
`/blog/` and in the "Writing" section on the home page.

## Local development

```bash
bundle install
bundle exec jekyll serve
# open http://localhost:4000
```

## Structure

```
_config.yml            Site config + plugins (seo-tag, sitemap, feed)
_data/                 All editable content (YAML)
_layouts/
  desktop.html         The Ubuntu desktop (home page)
  default.html         Simple shell for blog / 404
  post.html            Blog post
_includes/
  desktop/             boot, topbar, dock, desktop icons
  windows/             one file per app window (terminal, about, projects…)
  appicons.html        Yaru-style SVG icon set
  head.html            SEO meta + fonts + JSON-LD
assets/css/main.scss   Ubuntu/Yaru theme (compiles to main.css)
assets/js/main.js      Window manager + interactive terminal
assets/img/            OG image + favicons
index.html             Home → desktop layout
blog.html              Blog index
_posts/                Blog posts
```

## Terminal commands

The in-page terminal supports: `help`, `about`, `whoami`, `projects`,
`experience`, `skills`, `contact`, `neofetch`, `ls`, `social`, `open <app>`,
`clear` (plus up/down history). All content comes from `_data`.

## Regenerating the social/OG image

The 1200×630 share image and favicons are generated by a Pillow script kept in
version history; edit `assets/img/og-image.png` or regenerate as needed.
